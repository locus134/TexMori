# TexMori 工作台

面向游戏资源制作者，在导出前检查真实纹理的块失真、通道和体积。领域：纹理、通道、块、编码尺寸、Mip、容器、队列。色彩来自图像编辑器：炭灰画布、石墨面板、透明棋盘、白色像素标尺、蓝色选择线；语义色只表示状态。

核心视觉是同一区域原图与编码结果的同步对比。避免统计卡片、营销标题、装饰渐变。左资源列表 244px，右参数 284px，余下全部留给预览。边框和轻微明度差建立层级，无卡片阴影。

组件共同约束：系统中文字体，正文 13px，元数据 11px，标题 16px/600；数值等宽。4px 间距基数，控制区内边距 16px，分组间距 24px。主操作蓝色，其余中性灰。原生 button/select/dialog，明确 focus、disabled、空、加载、错误状态。窄窗口通过显式折叠侧栏保留预览，减少动态效果偏好受尊重。

资源列表：紧凑缩略图+名称+尺寸/格式+状态；预览：最大空间、像素比例、两种对比模式和统一视口；参数：格式和容器领先、条件参数后随；底栏：真实文件计数进度与操作。所有组件采用上述 Intent、Hierarchy、Palette、Depth、Surfaces、Typography、Spacing。
